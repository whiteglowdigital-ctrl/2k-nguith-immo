# Almakhtoum Immo

Site vitrine de l'Agence Immobilière Almakhtoum, Thiès (Parcelles Assainies Unité 2).

Site statique publié avec GitHub Pages : `index.html` et le dossier `img/`.

## Remplacer les photos

Déposez les vraies photos dans `img/` en gardant exactement le même nom de fichier :

- `accueil.jpg` (1800×1100) et `accueil-mobile.jpg` (900×1400)
- `bien-<code>-carte.jpg` (1000×1250, portrait), puis `bien-<code>-1.jpg`, `-2.jpg`, `-3.jpg` (1400×900) pour la galerie.
  Codes : `fahu`, `kmg2`, `pa-u3`, `grand-standing`, `diobass`
- `terrain-pallo.jpg`, `terrain-djibril-thiombane.jpg`, `terrain-mont-rolland.jpg` (1400×1050)
- `proprietaires.jpg` (1200×1500)
- `service-voyage.jpg`, `service-assurance.jpg`, `service-automobile.jpg` (800×560)

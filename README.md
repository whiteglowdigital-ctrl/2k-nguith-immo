# Jëfya Immo

Site de démonstration pour agence immobilière, publié avec GitHub Pages. Les biens, les avis et les photos sont des exemples.

- Code source (React + Tailwind) : branche `claude/2k-nguith-maquette`, dossier `jefya-immo-react/`.
- Ce qui est publié ici est la version compilée : `index.html` et le dossier `assets/`.
- Pour mettre à jour : `npm run build` dans `jefya-immo-react/`, puis copier le contenu de `dist/` à la racine de `main`.

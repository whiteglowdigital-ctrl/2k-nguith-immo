# 2K Nguith Immo

Maquette du site de l'agence 2K Nguith Immo (Dakar), publiée avec GitHub Pages à la racine de ce dépôt.

- Code source (React + Tailwind) : branche `claude/2k-nguith-maquette`, dossier `2k-nguith-react/`.
- Ce qui est publié ici est la version compilée : `index.html` et le dossier `assets/`.
- Pour mettre à jour : `npm run build` dans `2k-nguith-react/`, puis copier le contenu de `dist/` à la racine de `main`.

L'ancien site Almakhtoum Immo (Thiès) reste disponible dans l'historique Git (commit `610f59e`).

# 2K Nguith Immo : site React + Tailwind

```bash
npm install
npm run dev      # développement
npm run build    # site prêt à publier dans dist/
```

- Contenu (biens, contact, FAQ, photos) : `src/data/site.js`
- Une section = un composant dans `src/components/`
- Couleurs et polices : `tailwind.config.js`
- Ce qui reste à fournir est écrit [entre crochets] dans le site.
